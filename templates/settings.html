Your data, backup and moving to another computer

Everything you enter is saved on this computer the moment you save it, and is there again the next time the app starts:
  • settings: {{ settings_path }}
  • invoices and expenses: {{ db_path }}{% if counts %} ({{ counts.invoices }} invoice(s), {{ counts.expenses }} expense(s)){% endif %}
  • proofs: {{ data_dir }}/attachments/
Download a backup — one zip file with the settings, all invoices and expenses, the proofs, the rates file and the CAEN list.
Keep it somewhere safe, or copy it to another computer that has the tracker and restore it there.
